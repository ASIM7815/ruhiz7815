WHAT EACH VARIABLE DOES:
-------------------------

1. DATABASE_URL
   - Your PostgreSQL database connection string
   - Used by Prisma to connect to Supabase database
   - Contains username, password, host, port, and database name

2. NEXT_PUBLIC_SUPABASE_URL
   - Your Supabase project URL
   - Public variable (accessible in browser)
   - Used by Supabase client to connect to your project

3. NEXT_PUBLIC_SUPABASE_ANON_KEY
   - Public anonymous key for Supabase
   - Public variable (accessible in browser)
   - Used for client-side authentication
   - Safe to expose - has Row Level Security (RLS) protection

4. SUPABASE_SERVICE_ROLE_KEY
   - Private service role key
   - NEVER expose in browser/client code
   - Used for server-side operations that bypass RLS
   - Has full database access

SECURITY NOTES:
---------------
✅ NEXT_PUBLIC_* variables are safe to expose (they're public)
❌ SUPABASE_SERVICE_ROLE_KEY must NEVER be exposed to client
✅ All keys are already configured correctly in your code
✅ Service role key is only used in server-side code
