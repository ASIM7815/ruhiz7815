HOW AUTHENTICATION WORKS NOW:
------------------------------
1. User clicks "Sign in with Google" on /login
2. Redirects to Supabase Auth with Google OAuth
3. User selects Gmail account
4. Google redirects to Supabase: https://ybmauetbeakurugikmpb.supabase.co/auth/v1/callback
5. Supabase processes auth and redirects to: https://ruhiz.asimsaadz.com/auth/callback
6. Our callback route sets cookies and redirects to /dashboard
7. All API routes use requireAuth() to verify the session
8. All client components use useSupabaseUser() to access user data

IMPORTANT NOTES:
----------------
- User data is stored in Supabase Auth (auth.users table)
- User profile data is stored in your Prisma database (User table)
- The user.id from Supabase matches the id in your database
- Sessions are managed via HTTP-only cookies
- No more JWT tokens in localStorage
