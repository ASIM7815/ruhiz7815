✅ STEP 1: Get Your Service Role Key
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://supabase.com/dashboard
2. Select your project: RUHIZ
3. Click "Settings" (gear icon) in the left sidebar
4. Click "API" under Project Settings
5. Scroll down to "Project API keys"
6. Copy the "service_role" key (NOT the anon key)
7. Add it to your .env.local file:
   
   SUPABASE_SERVICE_ROLE_KEY="paste-your-service-role-key-here"


✅ STEP 2: Create Database Tables
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://supabase.com/dashboard
2. Select your project: RUHIZ
3. Click "SQL Editor" in the left sidebar
4. Click "New Query" button
5. Open the file: supabase-setup-complete.sql (in your project root)
6. Copy ALL the SQL code from that file
7. Paste it into the Supabase SQL Editor
8. Click "Run" button (or press Ctrl+Enter)
9. Wait for "Success. No rows returned" message

This will create:
  ✓ Direct messaging tables (conversations, messages, reactions)
  ✓ Group messaging tables (group chats for projects/study groups)
  ✓ Performance indexes
  ✓ Real-time subscriptions
  ✓ Row Level Security policies (so users can only see their own messages)


✅ STEP 3: Verify Setup
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. In Supabase dashboard, click "Table Editor"
2. You should see these tables:
   - conversations
   - conversation_participants
   - direct_messages
   - message_reactions
   - group_conversations
   - group_participants
   - group_messages
   - group_message_reactions

3. Click on any table and check the "RLS" badge is enabled


✅ STEP 4: Test Messaging
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Make sure your dev server is running (npm run dev)
2. Open: http://localhost:3000
3. Login with Google (you'll need to set up Google OAuth next)
4. Go to Messages page
5. Try searching for another user by their 5-digit UID
6. Send a message - it should appear instantly!
