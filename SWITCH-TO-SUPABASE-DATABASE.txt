✅ STEP 1: Run SQL in Supabase
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://supabase.com/dashboard
2. Select your project: RUHIZ
3. Click "SQL Editor" in the left sidebar
4. Click "New Query"
5. Open file: supabase-auth-tables.sql
6. Copy ALL the SQL (it's about 500 lines)
7. Paste into Supabase SQL Editor
8. Click "Run" (or Ctrl+Enter)

This will create:
✓ Users table (with Gmail, UID, profile data)
✓ Accounts table (Google OAuth data)
✓ Sessions table (login sessions)
✓ Projects, Study Groups, Startups tables
✓ Marketplace, Resources, Notifications tables
✓ All security policies (RLS)


✅ STEP 2: Update .env.local
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Get your Supabase PostgreSQL connection string:

1. In Supabase dashboard, go to: Settings → Database
2. Scroll to "Connection string" section
3. Select "URI" tab
4. Copy the connection string (looks like):
   postgresql://postgres.[PROJECT-REF]:[PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres

5. Replace [PASSWORD] with your database password
   (If you don't know it, you can reset it in Settings → Database)

6. Update your .env.local:

   DATABASE_URL="postgresql://postgres.ybmauetbeakurugikmpb:[YOUR-PASSWORD]@aws-0-us-east-1.pooler.supabase.com:6543/postgres?pgbouncer=true"
   DATABASE_AUTH_TOKEN=""


✅ STEP 3: Update Prisma Schema
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Change datasource in prisma/schema.prisma from:

  datasource db {
    provider = "sqlite"
  }

To:

  datasource db {
    provider = "postgresql"
  }


✅ STEP 4: Update Database Client
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Update src/lib/db.ts to remove the LibSQL adapter:

  import { PrismaClient } from "@/generated/prisma/client";

  const globalForPrisma = globalThis as unknown as {
    prisma: PrismaClient | undefined;
  };

  export const db = globalForPrisma.prisma ?? new PrismaClient();

  if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = db;


✅ STEP 5: Regenerate Prisma Client
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run these commands:

  npx prisma generate
  npm run dev
